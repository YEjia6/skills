# 可移植规则管理器
- 档案ID：PLM-20261104-01
- 功能名称：规则执行可靠性治理
- 模块：portable-rules-manager
- 功能说明：管理统一规则源、作用域、跨工具同步与回写；增加发布完整性检查及规则反馈退役指导。
- 业务流程：明确目标 → 按需取证与准入 → 编写规则 → 发布前检查 → 当前工具同步 → 分层验证 → 反馈修正。
- 当前状态：源包完成，运行回归通过，客户端模型行为尚未实测。
- 版本：1.4.0
- 版本演进历史：[history.md](history.md)
- 关键决策：规则源格式保持 v1；不强制目录重构或固定开发顺序；不把文件一致性当作模型遵守证据。
- 技术细节：scripts/rules_manager.py 的 body_readiness_errors 与 validate 发布模式；tests/test_rules_manager.py 覆盖拒绝无写入、有效正文及禁用候选。
- 依赖关系：Python 3.10+ 标准库；技能结构校验工具额外依赖 PyYAML，使用桌面捆绑环境。
