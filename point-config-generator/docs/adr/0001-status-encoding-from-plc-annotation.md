# 状态信号编码以 PLC 注释为唯一依据

生成《设备点位配置表》的启动/结束/故障信号时，唯一依据是 PLC 人员输入表点位名称中的状态注释（如「状态（0-待机 1-故障 2-运行）」），而非历史 Excel 副本或库中存量行。山东258 项目中 Excel 副本把 M160116 瓶检重秤 device_status 写为 启动1/结束0/故障2，但 mysqldump 真源 sd258.sql 中库行为 2/0/1，与 PLC 注释（0-待机=结束、2-运行=启动、1-故障）一致——证明副本该格是人工誊写错误，库行才是正确值。此规则写入技能生成器：无注释时按默认 启动1/结束0/故障空 处理并在校验报告告警，要求人工核对。

Considered Options: 以历史 Excel 副本为基准（被否——副本存在已证实的人工错误，且历史行可能是旧版规则）；以库中存量为基准（被否——库中可能存在历史上的人工误配，且新项目无存量可依）。

Consequences: 每个项目试跑时必须用库真源逐字段比对来验证映射表（山东258 的比对基线为 equipment_point_config 中 M160102/M160114/M160116/M1613 现存行）；PLC 注释本身错误时需 PLC 人员确认，技能不自行裁决。
