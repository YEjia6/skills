# 文档模板

按项目实际对象重复以下行或章节。使用相对链接连接交付文件；源码位置以项目根为基准。没有对应行为的字段写明判断依据。

## 总目录.md

记录分析基线、覆盖范围、交付状态，链接系统架构、业务流程、模块说明和覆盖清单。逐功能列出“功能标识｜名称｜入口｜流程链接｜模块文档链接｜实现位置｜验证位置或缺口”。

## 系统架构.md

列出部署单元及其启动依据、模块职责、依赖方向、数据所有者、外部接口和运行边界。用一条实际请求或异步事件串起入口、处理、存储及结果。注明声明的部署方式与已验证的运行情况。

## 业务流程/流程标识.md

填写触发者、入口、前置状态、成功终态。按顺序写“步骤｜负责模块和符号｜决策条件｜状态或数据变化｜后继步骤｜证据”。分支应指向实际结果，包括失败、中止、重试或补偿（实现存在时）。跨进程时同时给出发送与接收依据，例如主题和订阅配置。

## 模块/模块标识.md

记录职责、上下游、入口和关联流程。每个功能记录输入输出、权限及其执行位置、前置条件、状态转换、副作用、失败行为、源码和测试依据。无独立算法的功能注明实际处理步骤。

对计算或决策算法单设章节，写明入口、数据结构及其影响、执行顺序、比较和决胜条件、边界及异常。用与真实分支对应的伪代码表示处理过程。给出正常及边界输入、中间值、预期结果和验证方式。给出复杂度时定义规模变量，分开说明内存计算与外部访问。推断的热点列明依据，实测指标附命令、数据规模和测量条件。

## 覆盖清单.md

- 基线表：项目、工作树、版本、状态、文件摘要清单位置。
- 模块表：稳定标识、路径、类别、发现依据、依赖、批次、分析结论、文档链接或分类理由。
- 入口表：入口标识、注册证据、功能、流程、处理位置、验证依据。
- 批次表：标识、成员、状态、已覆盖入口、待接续调用、待复核原因。
- 未知与差异表：对象、证据、已查范围、影响、所缺材料。
- 验收记录：检查项、实际检查范围、结果、剩余问题、下一批或完成状态。
